# Dilemma Procyon `feuerdev` keymap

This keymap currently starts as a direct copy of the upstream BastardKB
`vendor` keymap for `bastardkb/dilemma/3x5_3_procyon`.

It is intentionally only a scaffold. The Totem/Scylla-inspired `feuerdev`
layout still needs to be ported after the stock Procyon firmware target has
been verified on the keyboard.

## Customizing the keymap

The scaffold supports VIA, encoder maps, and the Procyon/MaxTouch pointing
device settings inherited from the upstream keymap.
